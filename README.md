# Flight_Eda_dashboard_using_sql-and-streamlit
An interactive web application built with *Streamlit* to analyze and search flight data between major Indian cities. This project provides visual insights into airline market share and flight frequency.

## 🚀 Features
- *Flight Search Engine*: Filter flights based on source and destination (e.g., Bangalore to Delhi).
- *Market Share Analysis*: Interactive pie charts showing the distribution of different airlines.
- *Trend Visualization*: Line plots to track flight frequencies over time.
- *Detailed Data View*: Clean tabular display of flight routes, durations, and stops.

## 🛠️ Tech Stack
- *Frontend*: Streamlit
- *Data Analysis*: Pandas, NumPy
- *Visualizations*: Plotly / Matplotlib
- *Database/Storage*: CSV / SQL (based on your implementation)
